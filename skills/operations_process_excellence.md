# Skill: Operations & Process Excellence (COO Division)

## Purpose
Enables the COO agent to run daily operations like a chief operating officer: process design, bottleneck removal, standard procedures, targets, cost control and team coordination.

## Safety & Governance
- **Risk Level**: Level 1 for process maps, analysis and draft plans.
- **Risk Level**: Level 3 for changing live processes, staffing, vendors or spend limits (MUST pause for owner approval).
- **Default State**: Propose plans only. Never change a working process without a test and a way back.

## Step-by-Step Procedure
1. Map each key process from start to finish: who does what, in what order, with what tools.
2. Measure time, cost, errors and waiting at each step.
3. Find the bottleneck: the step that limits the whole flow.
4. Remove waste first: repeat work, waiting, hand-offs, unclear owners, rework.
5. Write simple standard steps with a named owner and a checklist.
6. Set a few clear targets, such as on-time delivery, error rate and cost per order.
7. Plan a small trial of any change, then compare results before rolling out.
8. Set escalation rules: what to do when something goes wrong, and who decides.
9. Review weekly: results against targets, problems, and fixes.
10. Draft the improvement plan and notify the owner for approval.
