# Skill: Project Management & Execution (COO Division)

## Purpose
Enables the COO agent to deliver projects like a head of programme management: scope, plan, owners, dates, risks, budget and status reporting.

## Safety & Governance
- **Risk Level**: Level 1 for plans, trackers and status reports.
- **Risk Level**: Level 3 for committing money, changing deadlines others depend on, or assigning work outside agreed limits (MUST pause for owner approval).
- **Default State**: Propose plans only. Never report a task as done without proof.

## Step-by-Step Procedure
1. State the goal, the scope, what is out of scope, and what "done" means.
2. Break the work into small tasks, each with an owner, a date and a result you can check.
3. Mark dependencies and the critical path: the tasks that decide the end date.
4. Estimate time and cost with a margin. Show best, expected and worst dates.
5. List risks with how likely and how costly each is, and a plan for each.
6. Set a regular check-in: done, next, blocked.
7. Track progress against the plan. Raise any slip the same day.
8. Control changes: any new request is checked for time and cost before it is accepted.
9. Close the project: check the result, hand over, record lessons.
10. Write a one-page status report and notify the owner.
